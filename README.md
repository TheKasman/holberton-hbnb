# HBnB

This repository contains the deliverables for the HBnB project, an AirBnB-like application built progressively across multiple parts.  

---

## 📁 Project Structure

| Part | Focus | Link |
|------|-------|------|
| Part 1 | System design, architecture planning, class modelling, sequence diagrams | [Part 1 README](part1/README.md) |
| Part 2 | RESTful API with Flask, business logic layer, in-memory persistence | [Part 2 README](part2/README.md) |
| Part 3 | Authentication, authorization, and persistent storage with SQLAlchemy | [Part 3 README](part3/README.md) |
| Part 4 | Simple web client with HTML5, CSS3, and JavaScript ES6 | [Part 4 README](part4/README.md) |
